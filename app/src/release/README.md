# spring-boot-restless

This artifact has no classes of its own. It depends on:

- `spring-boot-restless-read`: read-only resources, the filter DSL, named read actions and views,
  embedding and authorization.
- `spring-boot-restless-write`: create, update, patch and delete, bulk writes, write actions and
  lifecycle hooks, built on top of `-read`.

Sources and Javadoc are published with those two artifacts.
